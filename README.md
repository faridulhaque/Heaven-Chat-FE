## 🚀 Overview
**Heaven Chat** is a real-time messaging and calling application built for instant communication, enriched with an integrated AI assistant.


## 🧩 Features
- 🔐 **Google Sign In**
- 💬 **Real-time Chat**
- 📞 **Real-time Calling**
- 🤖 **AI Assistant**
- 🟢 **Online Status Presence**

## 🚧 Future Improvements
- Message reactions
- Video calling
- Chat search
- File sharing
- Typing indicators

## 🧰 Tech Stack

### Backend

### Frontend

## ⚙️ Installation (Local Setup)

1. **Clone the repository**
   ```bash
   git clone https://github.com/faridulhaque/Heaven-Chat-FE.git
   cd Heaven-Chat-FE

2. **Install dependencies**

    npm install


3. **Create a .env.local file and add:**

```env
NEXT_PUBLIC_BASE_URL=
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=
NEXT_PUBLIC_X_API_KEY=
NEXT_PUBLIC_ROUTER_AI_KEY=


```


4. **Run the development server**

    npm run dev


5. **Open in browser**

    http://localhost:3000
